# Johnny Abi Zeid Daou — Engineering Portfolio

A responsive personal portfolio focused on RF systems, SDR research, embedded hardware, and electronics projects.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive styling
- `resume.pdf` — résumé linked from the homepage
- `images/` — project photos, schematics, plots, and diagrams

## Run locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Publish with GitHub Pages

1. Create a GitHub repository for the site.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages** and select the `main` branch and `/ (root)` as the source.
4. Save and wait for GitHub Pages to publish the site.

## Before publishing

- Verify that the résumé is current.
- Add your real LinkedIn and GitHub profile links when ready; placeholder links have intentionally been removed.
- Replace the secure robot PCB placeholder panel with a real board layout or prototype photo when available.
- Review all project claims and clearly distinguish completed measurements from targets for in-progress work.

External Google Fonts are used when a network connection is available; fallback fonts will be used otherwise.
